# Akool plugin

Create AI videos, images, voiceovers, talking avatars and face swaps with your Akool account.

You need an Akool account.

## Install in Claude Code

```sh
claude plugin marketplace add AKOOL-Official/skills
claude plugin install akool@akool
```

Then start a new session. The first time you use it, sign in to Akool: run `/mcp`, select `akool`, and choose Authenticate.

## Install in Claude (claude.ai)

1. Open Plugins and choose Add → Add marketplace.
2. Enter `AKOOL-Official/skills`.
3. Install Akool, then connect it and sign in to your Akool account.

## Layout

`plugins/akool` also holds `plugin.json` and `mcp.json`, the same package Akool submits to the OpenAI plugin directory.
